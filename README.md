#  Global Streaming Landscape: Netflix Data Analysis Dashboard

An interactive and comprehensive data visualization project built using **Tableau**, diving deep into Netflix's content library to uncover production trends, audience targeting strategies, and regional distribution insights.

---

##  Project Overview
This project transforms raw streaming data into interactive, actionable visual insights. It explores how Netflix expanded its library globally, which genres and ratings dominate the platform, and how content production has evolved over time—all wrapped in a sleek, Netflix-inspired dark UI.

---

##  Key Insights
- **Content Dominance:** Movies make up the vast majority of the library at **over 68%**, compared to **31.5%** for TV Shows.
- **Audience Targeting:** A strong strategic focus on mature and young-adult audiences, with **TV-MA** and **TV-14** being the most prevalent ratings.
- **Production Trends:** A massive surge in content additions leading up to **2019**, reflecting the platform's aggressive global expansion strategy during that period.
- **Genre Preferences:** Documentaries and Stand-Up Comedy rank among the top popular genres, indicating high viewer demand for non-fiction and entertainment content.
- **Geographic Reach:** The United States serves as the primary hub for content production, backed by robust contributions from major international markets.

---

##  Technical Implementation

### 1. Data Preparation & Cleaning
- Handled missing values and standardized text fields.
- Ensured accurate date/time formatting for temporal analysis.

### 2. Data Visualization & Tableau Features
- **Geospatial Analysis:** Interactive maps displaying content production distribution by country.
- **Time-Series Analysis:** Area charts tracking content growth and release trends over the years.
- **Categorical Analysis:** Bar charts and distribution plots highlighting top genres and rating categories.
- **Interactive Filters:** Dynamic filtering enabling users to drill down into specific titles, release years, and genres for personalized exploration.

### 3. UI/UX Design
- Designed with a clean, **dark-themed interface** aligned with Netflix’s iconic branding to enhance readability and user engagement.
